FLOOD ALERT SYSTEM :

The Flood Alert System is an advanced solution designed to provide real-time situational awareness and proactive disaster management. By integrating high-resolution Google Earth data, leveraging machine learning algorithms, and offering immediate access to emergency resources, this system empowers citizens and authorities to act promptly and effectively during flood emergencies.

KEY FEATURES: 

Real-Time Situational Awareness:
-Integration with Google Earth for live updates on flood-prone areas and water levels.

Advanced Flood Forecasting:
-Utilizes machine learning algorithms to predict disaster trends and identify vulnerabilities.

Citizen Support and Accessibility:
-Instant Alerts: Real-time updates about floods, evacuation routes, and emergency shelters.
-Emergency Assistance: Direct access to support teams through a user-friendly mobile application.

Mobile Application:
-Intuitive Design: Seamless access to flood-related data, emergency contacts, and resources.
-Push Notifications: Timely updates on evolving flood situations
